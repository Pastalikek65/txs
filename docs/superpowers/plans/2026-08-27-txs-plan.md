# Termux Station (txs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `txs` — single-binary TUI dashboard for Termux that shows GitHub repos, job queue, SQLite DBs, system stats, and files in 5 panels, 15M binary, 50MB RAM, offline.

**Architecture:** Single Go binary `cobra` + `bubbletea` + `lipgloss` + `modernc.org/sqlite` WAL. 5 isolated panels (`panel/github`, `panel/jobs`, `panel/db`, `panel/sys`, `panel/files`) share only `store.Store` via `~/.cache/txs/txs.db`. `tui/root.go` routes `tab`.

**Tech Stack:** Go 1.25, cobra, bubbletea 1.3.4, lipgloss 1.1.0, modernc.org/sqlite 1.38.2, golang.org/x/term, gopsutil (or /proc parse), `CGO_ENABLED=0`, `trimpath`

## Global Constraints

- Go 1.25, `CGO_ENABLED=0`, `trimpath`, `-ldflags="-s -w -X main.version={{.Version}}"`
- Binary <20M, RAM <50M, `go build` <10s, `go test ./...` 70%+ in <30s, no CGO, no Docker, no daemon
- Cache `~/.cache/txs/txs.db` WAL `0700`, 5 tables, `XDG_CACHE_HOME` support, `android-arm64` + `linux-arm64` goreleaser
- `term.IsTerminal` plain fallback, `GH_TOKEN` precedence, `PathEscape` for user, `Link` pagination, `15s` fetch timeout

```go
// store/store.go
package store
import ("database/sql"; _ "modernc.org/sqlite"; "path/filepath"; "os")
type Repo struct {Name string; Stars int; Language string; UpdatedAt string; URL string}
type Job struct {ID int64; Cmd string; Status string; Retries int}
type Store struct{db *sql.DB}
func Open(path string) (*Store,error) {
    os.MkdirAll(filepath.Dir(path),0700)
    db,_:=sql.Open("sqlite",path)
    db.Exec("PRAGMA journal_mode=WAL")
    db.Exec("CREATE TABLE IF NOT EXISTS repos(name TEXT, stars INT, language TEXT, updated_at TEXT, url TEXT PRIMARY KEY)")
    db.Exec("CREATE TABLE IF NOT EXISTS jobs(id INTEGER PRIMARY KEY AUTOINCREMENT, cmd TEXT, status TEXT, retries INT)")
    return &Store{db:db},nil
}
func (s *Store) UpsertRepos(r []Repo) error { /* INSERT OR REPLACE */ return nil }
func (s *Store) ListRepos(sortBy string) ([]Repo,error) { /* switch sortBy */ return nil,nil }
func (s *Store) PushJob(cmd string) (int64,error) { /* INSERT */ return 1,nil }
func (s *Store) ListJobs(status string) ([]Job,error) { return nil,nil }
func (s *Store) Close() error { return s.db.Close() }
```
